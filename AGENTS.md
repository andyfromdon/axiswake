# Axis build instructions

- Keep this build separate from Malibu and APWS.
- Use Next.js, TypeScript, Node.js 24, GitHub and SiteHost.
- Reuse the Malibu visual template, with official Axis assets and content.
- New Zealand English; never invent local prices, availability, warranty terms, specifications or stock.
- International range and specifications must be labelled; record official source URLs.
- Noindex until a separate production launch decision.
- Never commit .env files, keys, credentials or customer data.
- Deploy only through an Axis-specific container and restricted deployment access.
- Validate the standalone release and its health endpoint before deployment.
